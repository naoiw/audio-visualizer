# 画面と機能の仕様

## 概要

ブラウザの画面共有で許可された音声トラックをWeb Audio APIで解析し、リアルタイムにCanvas表示する単一ページのWebアプリ。

## 音声入力

- ユーザーのクリック後に `navigator.mediaDevices.getDisplayMedia({ video: true, audio: true })` を呼び出す。
- 音声キャプチャは必ず共有ダイアログ経由で行う。無断キャプチャはしない。
- ブラウザによって共有できる範囲が異なる。タブ音声は比較的対応が広いが、ウィンドウやPC全体の音声はOS・ブラウザの制限を受ける。
- 音声トラックのない共有を検出し、全トラックを停止してエラーを表示する。
- `MediaStreamAudioSourceNode → AnalyserNode` に接続する。再生先 `AudioContext.destination` には接続しないため、音声を二重再生しない。
- 共有した音声を外部サーバーにアップロード、保存、配信しない。
- 画面共有・音声共有のトラックが終了したら解析を停止する。アプリ側からの停止とアンマウント時にもリソースを破棄する。
- 共有ダイアログ表示中の処理がキャンセル・アンマウントより遅れて完了しても、古いストリームを再利用しない。

## 波形モード

- 初期表示。 `AnalyserNode.getByteTimeDomainData` により時間領域の8ビットデータを読む。
- FFTサイズ2048（同じ数のサンプル）をキャンバスの横方向に連続線として表示する。
- サンプル値0〜255を上下に写像する（約128が中心）。横軸は短時間のサンプル列であり、秒単位の履歴ではない。
- 無音時は中心付近の水平線になる。

## 周波数モード

- `AnalyserNode.getByteFrequencyData` で周波数領域データを取得する。
- FFTサイズ2048、周波数ビン数1024、スムージング係数0.7、表示上限16,000 Hz。
- ナイキスト周波数を超えるビンは描画しない。
- 対象ビンを最大100列に集約し、各列は範囲内の最大値で高さを決める。横軸は線形周波数。
- 縦軸はAnalyserNodeが返す0〜255の相対強度で、校正済みの音圧レベル（dB SPL）ではない。

## 表示と状態

- 画面上部：アプリ名、タイトル、共有状態（停止中／共有を選択中／取得中）
- グラフ：波形／周波数の切り替え、Canvas、軸の簡易表示、FFTサイズ、サンプルレート
- 下部：共有開始／共有停止ボタンと注意事項
- 共有要求中は開始ボタンを無効化。OS側から共有を停止した場合も状態を戻す。
- 画面幅に合わせてCanvasをリサイズし、高DPIでは実ピクセル数を増やして描画する。
- スマートフォン向けの幅でもコントロールを使えるレイアウトとするが、モバイルOSの音声共有可否は保証しない。

## 安全と制約

- `getDisplayMedia` はHTTPSまたはlocalhostなどのセキュアコンテキストを要求する。
- 一般的なブラウザのWebページから、アプリ外のPC音声を許可なしに取得することはできない。
- 録音・ファイル保存・マイク入力選択・遅延を伴う長期履歴の描画は現時点では行わない。
